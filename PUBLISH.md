# Publish WorkMeet on GitHub Pages

This is the fastest way to give someone a public link.

1. Open https://github.com/new
2. Repository name: `workmeet.io`
3. Visibility: Public
4. Create repository
5. Click **uploading an existing file**
6. Upload every file from this folder:
   - index.html
   - styles.css
   - app.js
   - manifest.json
   - icon.svg
   - README.md
7. Commit the files
8. Open **Settings → Pages**
9. Source: Deploy from a branch
10. Branch: `main`, folder: `/ (root)`
11. Save

Live URL after a few minutes:

`https://damsi757.github.io/workmeet.io/`

Share that link. Visitors click **Create account** or **Sign in**.
